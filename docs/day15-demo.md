# Day 15 demonstration and handover

## Live demo order
1. Launch app and create first administrator from login screen.
2. Admin creates incubator, programme and evaluator account.
3. Founder self-registers, signs in, creates startup and uploads a supporting document.
4. Founder submits incubation application; show application row and shared startup ID.
5. Evaluator signs in, enters innovation/market/feasibility/team scores and recommendation.
6. Mentor self-registers; admin approves mentor and assigns the mentor to the same startup.
7. Admin creates milestone; assigned mentor views assigned milestones and updates status with a progress note. Show the founder notification.
8. Founder creates funding request and uploads its supporting document; investor self-registers, adds sector preference and ticket range, views explainable matches and records an investment commitment. Show the founder notification and the remaining-amount protection.
9. Show Startup 360° readiness and connected application/mentor/milestone/funding totals.
10. Import the actual public CSV, view historical rounds and repeat import to demonstrate duplicate-safe behaviour.
11. Show dashboard totals, top startups by readiness, status/sector distributions, notifications and mark-read action, milestone health, activity timeline, generated log, then export and reopen the serialized snapshot.
12. Explain prepared statements, foreign keys, service-level role checks and transaction rollback.
