# Project Requirements Documentation

This directory contains the functional and technical requirements for the Startup Incubation & Investment Management Platform.

## Purpose

Each member is responsible for preparing and maintaining the requirements document for their assigned module.

These documents will be used as the reference for database design, application development, testing, and integration.

## Documentation Guidelines

- Each member should maintain their module requirements in a separate Markdown file.
- Changes should first be committed to the respective member's feature branch.
- Requirements documents should be reviewed before being merged into the main branch.
- The shared project requirements index should be updated when a module requirements document is added.

## Technology Stack

- Programming Language: Java
- GUI: JavaFX
- Database: MySQL
- Database Connectivity: JDBC
- Version Control: Git and GitHub
